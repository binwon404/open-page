파트별 핵심 키워드

1강목표의 관점·통합

  • 목표의 역할: 활동의 동기 · 판단기준 · 존재가치 지표
  • 합리적 관점 = 목표 달성 극대화 / 자연적 관점 = 상황 적응, 생존·유지 우선
  • 조화의 계기 = 기여에 대한 보상(물질적 + 비물질적)
  • 교환 = 외재적 보상 · 교화 = 가치 내면화 · 수용 = 조직이 개인목표 인정(자율)

1강목표 유형·충돌·변동

  • 공식목표 = 사명, 추상·포괄 / 운영목표 = 측정 가능·단기·자원배분
  • 공언(Stated) vs 실제(Real) 목표 불일치 → 갈등
  • 하위목표 많을수록 갈등 가능성↑ · 합의: 타협과 협상 / 반강제적 통제 / 재조정(정치적 행동)
  • 교체 = 기존 목표가 달성됐거나 달성 불가일 때 · 추가 = 부수 목표 병행
  • 왜곡(단체장 재선) · 수단 전도(병상 가동률) = 증강판의 목표전환

1강+SMART·MBO·OKR

  • Locke & Latham: 구체적이고 도전적인 목표 → 성과 (단, 수용되어야)
  • SMART = Specific·Measurable·Achievable·Relevant·Time-bound
  • MBO: 성과와 평가 직접 연결 → 한계 목표 부풀리기
  • OKR: 평가에서 분리 · 투명 공개 · 도전적 분기, 하나라도 빠지면 "MBO의 변주"
  • AI: 직무가 아닌 과업(task) 단위 · ESG: 두 번째 KPI 트리, 그린워싱 위험

1강유효성 접근법

  • 유효성 = 조직이 얼마나 잘 기능하는지 판단 기준, 지금은 목표·과정·결과 전반
  • 목표달성 전제 = 운영목표의 계량화 · 한계 = 목표 상충, 주관성 / "좋은 목표인가"는 안 물음
  • 시스템적 = 투입→변환→산출 전체 · 하위 두 갈래 자원기준 · 내부프로세스
  • 자원기준: 자원 보유 ≠ 효과적 사용 · 내부프로세스: 외부 평가자가 측정 어려움
  • 통합적: 이해관계자 접근법 + BSC(Kaplan & Norton)

1강경쟁가치·문화진단

  • 구성원 = 내부지향, 조직 = 외부지향
  • 네 모형·네 문화는 아래 "한 장 요약" 표로
  • OCAI: 6차원 × 현재 vs 5년 뒤 선호, 100점 배분
  • Kasa(2025) 혼합 하위문화
  • 정합 실패 3: 전략↔문화 · 문화↔지표 · 전략↔지표

2강구조·설계 기본

  • Blau = 지위 배분(위계) · Gerloff = 지도 · Child = 관리 메커니즘 · Ranson 등 = 상호작용
  • 설계 = 잘 나누고(differentiation) 잘 통합(integration)
  • 구조 = 상태·결과 / 설계 = 과정·결정의 묶음 (교안은 "같은 의미")
  • 역할: 분업·조정과 통합(일) / 의사결정과 통제(사람)
  • 과업구조 sub-structure / 부서구조 super-structure

2강분업화

  • 수평적 = 같은 수준에서 나눔 · 수직적 = 관리와 실천 분리
  • 직위가 올라갈수록 분업 최소화 · 반복·단순 기술일수록 분업 용이
  • 지나친 분업: 반복으로 오히려 효율 저하, 연결비용, 부서 갈등
  • 적정 수준 = 이득과 손실의 균형점
  • 분할 단위: 고정 직무 → 재구성 가능한 스킬 단위

2강통합화·조정

  • 공식화는 양이 아니라 얼마나 지켜지는지 · 과하면 융통성·창의성↓, 비인간화
  • 투입물 표준화 = 훈련·교육(making) · 자격자 선발(buying)
  • 상호 조정 = 위계적 권한 없이 조정 · 연결핀(liaison) = 중재자
  • 증강판 조정 5: 직접감독 → 규칙절차 → 목표설정 → 상호조정 문화 → 전담 통합자 (갈수록 무겁고 깊음)
  • 매트릭스 = 두 매니저에게 보고, 충돌·시간 두 배

2강통제·분권·현대 양식

  • 통제 = 권한 + 의사결정권이 누구에게 있는가 · 주체·대상·방식
  • 집권화 = 업무가 긴밀히 연결, 신속 결정 · 분권화 = 외부 변화 빠를 때
  • 통제 범위 ≠ 위임 · 위임 = 책임의 재배치 · 실패 신호: 권한은 내려가고 책무는 남음
  • Holacracy = 권한이 역할에 · 스킬 기반 = 일을 사람의 스킬에 맞춤
  • 기능형(안정·규모의 경제) · 사업부제(다중 시장) · 매트릭스(복잡 환경, 사일로)

3강상황요인

  • 상황적합성(Contingency): 구조는 상황에 따라 달라진다
  • 규모↑ → 공식화·표준화 · 연혁↑ → 관료화(복지부동)
  • 안정 목표 → 기계적 / 혁신 목표 → 유기적 · 권위주의 문화 → 기계적 / 참여적 → 유기적
  • Structure follows Strategy (반대도 발생) · 원가우위 → 기계적, 차별화 → 유기적
  • 홉스테드: 상하거리감↑ → 집권·높은 계층, 불확실성 회피↑ → 공식화·경직
  • 매개변수: 과업 불확실성↑ → 유기적 · 의존성↑ → 통합기제 강화

3강조직기술

  • 우드워드 = 기술결정론, one best way · 복잡성 단위 낮음 → 연속공정 높음
  • 단위·연속공정 = 유기적, 대량생산만 기계적 (U자)
  • 관리계층·관리자 비율 최다 = 연속공정 · 통제범위 최대 = 대량생산
  • 퍼로우 = 다양성 × 분석가능성, 부서 단위 · 장인 = 작업경험 / 공학 = 공식적 훈련
  • 톰슨: 집합적–중개형 · 순차적–연속형 · 교호적–집약형 (조정수단 누적)

3강환경 불확실성

  • 불확실성 3: 상태 · 결과 · 반응 (비 올까 / 할 수 있을까 / 어떻게 할까)
  • 단순/안정 < 복잡/안정 < 단순/동태 < 복잡/동태
  • 기계적 = 명령·지시, 권한 최고층 / 유기적 = 충고·자문, 권한 능력 있는 곳
  • Lawrence & Lorsch: 동태성 → 기계/유기, 복잡성 → 변경조직 수
  • 불확실성↑ → 차별화와 통합방법 둘 다 증가

MBO — Management by Objectives

Drucker(1954) 이후 가장 오래된 목표경영 체계. 평가와 맞물리면서 한계에 부딪힘.

네 가지 원리

  1. 상향 + 하향의 결합 — 상위 목표를 부문·개인으로 분해하고 합의
  2. 구체적이고 측정 가능 — “매출 12% 성장”처럼
  3. 정기적 점검과 피드백
  4. 성과와 평가의 직접 연결 — 보상·승진·개발의 근거

네 가지 한계

  • 정량화하기 어려운 목표를 잘 다루지 못함
  • 단기·측정 가능한 항목만 남고 학습·문화는 사라짐
  • 평가와 맞물리면 목표 부풀리기
  • 외부 환경 변화에 대한 적응이 느림

MBO에서 OKR로

O(Objective) = 방향과 의도를 한 문장으로(질적, 기억에 남는). KR(Key Results) = 측정 가능한 결과 세 줄.

예시내용
O“신규 사용자가 첫 10분 안에 가치를 느끼게 한다.”
KR 1첫 세션에서 핵심 기능을 완성한 신규 사용자 비율 35 → 60%
KR 2일주일 이상 머무는 신규 코호트 22 → 40%
KR 3신규 코호트 NPS 12 → 35 (분기 종료 시점)

MBO와의 세 가지 차이

  1. 평가·보상에서 분리 — 점수가 보상에 직접 연결되지 않음. 신호는 “의도가 무엇이었나”
  2. 투명하게 공개 — 누구의 OKR이든 볼 수 있음. 정렬과 학습의 장치
  3. 도전적이되 분기 단위 — 0.6~0.7 달성이 좋은 분기. stretch + 안전 토양
시험 포인트

형식만 도입하고 평가 분리 · 투명성 · 도전성 중 하나라도 빠뜨리면 OKR은 빠르게 “MBO의 변주”가 된다. MBO = 성과와 평가를 직접 연결 ↔ OKR = 평가에서 분리. 이 대비가 핵심.

조직유효성의 개념 · 용도 · 판단기준

조직이 목표를 효과적으로 달성해야 조직 안정과 유지가 가능. 조직유효성 = 조직이 얼마나 잘 기능하고 있는지를 판단하는 기준. 조직의 복잡성과 다양한 활동을 고려해 평가해야 합니다.

  • 용도: ① 잘하고 있는지·효율적인지 판단 ② 조직 선택 시 의사결정 기준(취업할 회사, 투자할 기업) ③ 과거 성과로 미래 개선 방향 제시
  • 판단기준: 생산성, 능률, 이익, 성장성, 재무건전성, 직무만족, 유연성, 상호일치성 등 다양. 연구자마다 중시하는 가치·관점이 달라 결과가 달라짐. 목표 달성 여부만이 아니라 평가 기준·기간·관점에 따라 판단이 달라짐 (“좋은 교수는? 좋은 학교는?”)
  • 무엇으로 볼 것인가: 초기 의견 = 조직목표가 유효성 판단의 조건(→ 누구의 목표? 단기? 장기? 부서? 전체?) / 현재 방향 = 목표, 과정, 결과 전반에 대해 판단

증강판 16쪽
구분효율성 Efficiency유효성 Effectiveness
질문“더 적은 자원으로 더 많은 산출을 내는가”“의도한 결과에 도달했는가 — 올바른 일을 했는가”

둘은 다르다. 효율적인 조직이 잘못된 목표를 빠르게 추구할 수 있고, 의미 있는 목표를 가진 조직이 비효율적일 수 있다.

용어 충돌 · 3강 교안

증강판 1강은 효율성 = efficiency, 유효성 = effectiveness. 그런데 3강 교안 17쪽(조직기술의 두 차원)은 “효율성(effectiveness): 조직목표에 가장 적합한 기술 / 능률성(efficiency): 작은 input을 큰 output으로”라고 적습니다. 영어 뜻은 두 자료가 같고(effectiveness = 목표 적합, efficiency = 투입 대비 산출) 한국어 라벨만 다릅니다. 영어로 기억하고, 3강 문제에서는 교안 표기를 따르세요.

수평적 분업동일한 수준에서 과업을 세부과업으로 나눔. 분업이 높을수록 한정된 부분만 담당 → 숙련도↑, 전체 조율 문제 발생 가능자동차 조립: 엔진·도어·타이어 조립
수직적 분업분업 1: 관리(계획·감독)와 실천(집행) 분리
분업 2: 관리업무 자체를 분야별로 분리 — 관리직의 수평적 분업		경영진(기획) vs 직원(실행) / 기획 파트 세분화

⇒ 규모가 작은 조직: 수평·수직 분업이 낮음, 한 사람이 다양한 역할. 규모가 큰 조직: 둘 다 강화 → 과업 세분화 + 관리층 다층화.

분업화 정도에 영향을 미치는 요소

분업화 정도 = 부서 특성 + 직위 수준 + 기술 수준 + 과업 성격

요소내용
부서의 특성같은 조직이라도 부서별로 다름. 조립부서는 매우 세분화, 회계부서는 덜 세분화
직위 수준직위가 올라갈수록 분업은 최소화
기술 수준반복적·단순 기술일수록 분업화 용이. 전문적·복잡한 기술은 과도한 분업 불가 → 통합 필요↑
연구·전문 영역지적·창의적 업무는 지나친 분업화 부적합. 과업 간 통합과 협력이 중요

적정 수준이 중요. 과도한 분업은 조정 비용·의사소통 문제 등 비효율을 초래.

지나친 분업화의 문제점 (분화의 비용)

문제내용
작업 범위 축소맡는 과업이 지나치게 작아짐. 단순 반복, 다양성·보람 감소
효율성 저하고정화(표준화)는 쉬워지지만 지나친 반복으로 숙련도가 높아져도 오히려 효율 저하
조율·연결 비용 증가세분화된 과업을 다시 조합·연결하는 비용. 경제적 비용 + 시간·노력
부서 간 갈등이해관계 충돌·목표 상충, 의사소통 어려움
무형의 비효율부서 간 단절 심화 → 유연성 저하. 협력보다 분절적 행동

요약: 작업방법 고정화 · 반복에 의한 낮은 효율 · 연결비용(경제적 비용, 갈등, 커뮤니케이션, 일의 지연).

분업화의 적정 수준 (교안 13쪽 그래프)

가로축 = 분업화 정도(적음 → 많음), 세로축 = 유형·무형의 이익과 손실. 분업화가 커질수록 한 곡선은 내려가고 한 곡선은 올라가며, 두 곡선이 만나는 지점 바로 위에 U자 곡선의 최저점이 놓입니다. 그 점이 적정 분업화 수준 — 분업화의 이득과 손실이 균형을 이루는 지점입니다. 분업은 “많을수록 좋다”가 아니라 적정 수준이 있다는 그림입니다.

교안 그림의 곡선 라벨(“분업화에 의한 이득” / “분업화로 인한 손실”)이 어느 곡선에 붙는지 그림만으로는 모호합니다. 답안은 “이득과 손실의 균형점”으로 쓰면 안전합니다.

통합화의 의미와 수단

나뉜 기능·작업집단이 다시 연결·통합되어야 목표 완수. 통합화(integration) = 분리된 과업과 부문 간 협동·상호 연계로 전체 목표 달성. 수평·수직으로 분화된 과업을 다시 조정·통합하는 과정.

  • 수평적 통합: 과업들 간의 조정(coordination)
  • 수직적 통합: 계획, 실행, 피드백, 지시·보고가 원활

수단 1 공식화

규정·규율을 미리 정해 통합적으로 조화

수단 2 표준화

규정된 절차와 방법을 동일하게 적용

수단 3 상호 조정

당사자 간 상호 소통으로 조정

(수단 1) 공식화 — 업무 방식과 절차를 규정화

분업된 과업들을 문서화된 규정·절차로 연결해 조정. ‘약속된 규칙’에 의해 협동·연결.

공식화와 문서화: 규정이 많아도 실제 집행에서 무시되거나 형식적이면 효과 없음 → 공식화 정도는 양이 아니라 얼마나 잘 지켜지는지가 중요.

지나친 공식화의 한계: ① 융통성 감소(상황 변화 대응 어려움) ② 창의성 감소(재량권 없음) ③ 비인간화·인간 소외(사기 저하).

(수단 2) 표준화 — 업무 방식과 생산과정의 통일

각 부서의 작업 방식, 행동 양식, 연락 방법, 산출물의 품질·수준을 사전에 통일해 규정.

시험 포인트 · 공식화 vs 표준화

공식화 = 규정·규칙·문서에 따라 업무 수행. 표준화 = 실제 작업 방식·절차를 동일하게 맞춤. “규정만 있는 것이 공식화라면, 실제 작업 과정과 산출물이 통일되는 것이 표준화.”

표준화 범위내용예
투입물의 표준화원료·부품·작업자의 기술과 자격. 작업자 행동의 표준화: 훈련·교육(making), 자격자 선발(buying)자격증 보유자 채용, 신입 교육
과정의 표준화작업 수행 절차와 과정을 동일하게 규정지침서, 절차 규정, 작업 매뉴얼
산출물의 표준화최종 산출물이 동일한 품질·수준 유지제품 규격, 서비스 품질 기준, 고객 응대 방식

(수단 3) 작업자 간 상호 조정

위계적 권한관계를 설정하지 않고도 과업을 조정하는 방법. 생산 현장·팀 단위에서 서로 업무를 맞추는 상호 조정(mutual adjustment). 기능·부서·계층 간 지속적이고 비공식적인 커뮤니케이션에 크게 의존.

방식내용

1. 조직규모

규모가 커질수록 공식화·분화·통합이 요구되고, 균형을 못 잡으면 경직성과 비효율.

  • 인원 수 증가 → 인간관계 수가 기하급수적으로 증가 → 조정 필요성 확대. nC2 = n(n−1)/2 (예: 10명이면 45개 관계)
  • 부서 수 증가 → 규정·규칙·공식화 강화, 조정 장치 필요 / 인원 증가 → 권한 위임과 공식화 확대
규모 증가→공식화→통제범위 확장→부서규모 증가

규모 확대 = 복잡성 증가 → 공식화와 표준화 강화. 그러나 지나친 공식화는 경직성·비효율.

2. 조직연혁

오래될수록 관료화·공식화 강화, 젊은 조직은 유연성·적응력이 높음.

  • 창업 초기: 작고 단순한 구조, 비공식적 운영 / 성장 이후: 부서 증가, 부서 간 의존성 증가 → 공식화·표준화 심화
  • 과거 성공 경험이 누적되며 관행·절차에 의존, 새 방식 도입이 어려움 → 안정적이지만 혁신·도전에 둔감
  • 연혁이 짧은 조직: 단순·유연, 빠른 적응 / 연혁이 긴 조직: 관료제적, 안정적이나 경직 위험(복지부동)

3. 조직목표

목표는 구조 설계의 기본 방향. 안정 지향 → 기계적 구조, 혁신 지향 → 유기적 구조.

  • 군대·테러조직: 개인보다 국가·집단 보호라는 상위 목표 / 기업: 이윤 극대화, 성장, 사회적 책임
  • 안정적 목표 → 안정성·효율성 → 관료적·기계적 / 혁신적 목표 → 창의성·유연성 → 분권적·유기적

4. 조직전략

전략이 구조를 이끄는 가장 중요한 요인이며, 전략과 구조의 적합성이 성과를 좌우. 부적합은 성과 저하.

“조직구조는 전략을 따른다(Structure follows Strategy)” — 경영학의 고전적 명제. 단, 반대(Strategy follows structure)도 현실에서 자주 발생: 경직된 집권화 구조 → 관료화 → 방어적·안정적 전략 / 분권화된 조직 → 혁신적·진취적 전략.

조직기술이란

과업을 수행하는 방법·절차·지식·도구 등을 포괄. 기계·장비만이 아니라 업무를 투입(Input) → 변환(Transformation) → 산출(Output)으로 전환하는 모든 활동.

  • 두 차원: 효율성(effectiveness) = 조직목표에 가장 적합한 기술 / 능률성(efficiency) = 작은 input을 큰 output으로 만드는 기술

용어 충돌

여기서 “효율성”은 effectiveness(목표 적합)입니다. 1강 증강판은 effectiveness를 유효성, efficiency를 효율성이라고 불렀습니다. 영어 기준으로 외우세요: effectiveness = 목표에 맞는가 / efficiency = 투입 대비 산출.

1. 우드워드(Woodward): 생산기술이 구조를 결정

기술에 따라 조직 적합성을 구현할 수 있다는 최초의 주장. 한 기술에 적합한 구조는 단 하나(one best way)라는 기술결정론(technological imperative)의 창시자.

복잡성(complexity): 1950년대 기계화 정도, 예측 가능성(고장의 이해·수리 가능 여부)으로 구분. 대부분 작업을 기계가 하면 복잡성 높음, 작업자가 하면 낮음.

환경 불확실성의 세 가지 측면

충분한 정보가 없어 변화나 결과를 정확히 예측할 수 없는 상태. 미래 예측만이 아니라 현재 상황조차 정확히 인식하지 못하는 경우도 포함. 환경이 복잡하고 변화가 잦을수록 불확실성↑.

측면의미예 (야외 팀빌딩)
